JWT - JSON web token  - состоит из 3 частей, разделенными
точками

1) Header (Заголовок) - инф о типе токена и использ
в алгоритме шифрования

2) Payload (полезная нагрузка) - (!_id!, role, username)

3) Signature (подпись) - для проверки целостности и зашиты
от изменений

JWT -> 'Header.Payload.Signature'
